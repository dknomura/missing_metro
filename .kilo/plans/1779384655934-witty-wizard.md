# Refactor `create_buffer_donuts` to use `clip_to_buffer_rings`

## Current State

- **`sb79map.py`** (notebook) defines `create_buffer_donuts` inline in `app.setup()`. It:
  1. Calls `trim_around_stations` 3× for 200ft, 1320ft, 2640ft
  2. Manually creates donuts via `gpd.overlay(..., how="difference")`
  3. Concatenates, computes area, assigns zone density, aggregates by APN

- **`geoprocessing.py`** has `clip_to_buffer_rings` which does sjoin → overlay(intersection) → donut subtraction — exactly matching steps 1–2 above, but returns results in the buffer CRS and passes full buffer columns to the internal overlay (causing column suffix noise).

- **`sb79.py`** already has `ZONE_DENSITIES`, `compute_scag_density`, and `trim_around_stations` (standalone, with its own Tier-renaming logic). The new method belongs here.

## Changes

### 1. `shared/utils/geoprocessing.py` — fix overlay column noise

Change line 63 in `clip_to_buffer_rings`:

```
gpd.overlay( gpd.sjoin(...), buf,        how="intersection")
                              ^^^
```
→
```
gpd.overlay( gpd.sjoin(...), buf[["geometry"]], how="intersection")
```

This avoids duplicate columns (with `_1`/`_2` suffixes) in the output. All buffer attributes already flow through from the `gpd.sjoin` step.

### 2. `shared/pipelines/sb79.py` — add `create_buffer_donuts`

Add a new function after `compute_scag_density` (around line 180):

```python
def create_buffer_donuts(
    stops_gdf: gpd.GeoDataFrame,
    scag_density: gpd.GeoDataFrame,
) -> gpd.GeoDataFrame:
```

Logic:
1. Trim stops to `["stop_id", "Tier", "geometry"]` (only columns needed)
2. Call `clip_to_buffer_rings(scag_density, stops_trimmed, [200, 1320, 2640], "EPSG:2229", "difference")`
3. Tag each of the 3 rings with `buffer_zone_id` (`"200ft"`, `"qtr_mi"`, `"half_mi"`)
4. `pd.concat` rings into one GDF (`residential`, already in EPSG:2229)
5. `area_sqft = residential.area` (no reprojection needed — result is already EPSG:2229)
6. Map `zone_density` from `ZONE_DENSITIES` dict via `(buffer_zone_id, Tier)` multi-index
7. Aggregate by `APN20` (same vectorized logic as current: weighted density, dwelling units, `unary_union` geometry, `additional_du`)
8. Return the result GDF

Imports to add at top of `sb79.py`:
- `from shared.utils.geoprocessing import clip_to_buffer_rings`
